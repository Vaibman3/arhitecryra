## Задание 2

**Исходное утверждение:**
x → (y ↔ z) = (x → y) ↔ (x → z)

Для доказательства используем следующие логические эквивалентности:
1. **Импликация:** A → B ≡ ¬A ∨ B
2. **Эквивалентность:** A ↔ B ≡ (A → B) ∧ (B → A) ≡ (¬A ∨ B) ∧ (¬B ∨ A)
3. **Дистрибутивность:** A ∨ (B ∧ C) ≡ (A ∨ B) ∧ (A ∨ C)

---

## Преобразование левой части (ЛЧ)

**x → (y ↔ z)**

Применим определение эквивалентности к внутренней скобке:
**≡ x → ((¬y ∨ z) ∧ (¬z ∨ y))**

Применим определение импликации:
**≡ ¬x ∨ ((¬y ∨ z) ∧ (¬z ∨ y))**

Раскроем скобки по дистрибутивности (операция ∨ дистрибутивна относительно ∧):
**≡ (¬x ∨ ¬y ∨ z) ∧ (¬x ∨ ¬z ∨ y)**

Перегруппируем слагаемые для наглядности:
**≡ (¬x ∨ ¬y ∨ z) ∧ (¬x ∨ ¬z ∨ y)**   *(это выражение 1)*

---

## Преобразование правой части (ПЧ)

**(x → y) ↔ (x → z)**

Применим определение эквивалентности к внешнему оператору:
**≡ ((x → y) → (x → z)) ∧ ((x → z) → (x → y))**

Применим определение импликации к внутренним и внешним частям:
**≡ (¬(x → y) ∨ (x → z)) ∧ (¬(x → z) ∨ (x → y))**

Так как ¬(x → y) ≡ (x ∧ ¬y), получаем:
**≡ ((x ∧ ¬y) ∨ (¬x ∨ z)) ∧ ((x ∧ ¬z) ∨ (¬x ∨ y))**

Раскроем скобки (дистрибутивность):
**≡ (x ∨ ¬x ∨ z) ∧ (¬y ∨ ¬x ∨ z) ∧ (x ∨ ¬x ∨ y) ∧ (¬z ∨ ¬x ∨ y)**

Так как (x ∨ ¬x) ≡ 1 (истина), а (1 ∨ A) ≡ 1, упрощаем:
**≡ 1 ∧ (¬x ∨ ¬y ∨ z) ∧ 1 ∧ (¬x ∨ ¬z ∨ y)**

Убираем константы 1:
**≡ (¬x ∨ ¬y ∨ z) ∧ (¬x ∨ ¬z ∨ y)**   *(это выражение 2)*

#### Класс S (самодвойственные функции)

**Вывод:** так как f1 и f3 не самодвойственны, система не содержится целиком в S.

#### Класс M (монотонные функции)

Функция монотонна, если для любых наборов a ≤ b выполняется f(a) ≤ f(b).

Рассмотрим f1. Возьмём наборы:
- a = (1,1,0), b = (1,1,1), причём a ≤ b.
- f1(a) = f1(1,1,0) = 1
- f1(b) = f1(1,1,1) = 0

Получили 1 > 0, значит f1 **не монотонна**.

**Вывод:** система не содержится целиком в M.

**Вывод:** так как f1 не линейна, система не содержится целиком в L.
